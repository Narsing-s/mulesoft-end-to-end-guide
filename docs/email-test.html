Greeting Email Test

This page checks the browser-side EmailJS configuration and can send one real test greeting to the currently signed-in local account. It never asks for an EmailJS private key or SMTP password.

Before testing: configure docs/email-config.js with your EmailJS public key, service ID and template ID, then make sure the template uses the variables documented in EMAIL-SETUP.md. EmailJS browser sending uses the public key and template/service identifiers; keep private credentials out of this public repository.
