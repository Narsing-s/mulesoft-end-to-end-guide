Mule Event Explained: Payload, Attributes and Variables

The Mule event is the most important mental model in Mule 4. Once you understand it, flows and DataWeave become much easier to reason about.

The event

A Mule event carries information through a flow. The main pieces beginners work with are the payload, attributes and variables.

Payload      → business data
Attributes   → metadata about the message
Variables    → values you explicitly store for later steps

Payload

If an HTTP request contains JSON, the request body is commonly available as the payload. A Transform Message can replace or reshape that payload.

#[payload.customer.name]

Attributes

Attributes describe the message context. With HTTP, they can include method, headers, query parameters and URI parameters.

#[attributes.queryParams.accountId]

Variables

Variables are useful for temporary values that should travel with the event.

<set-variable variableName="customerId" value="#[payload.id]"/>
Beginner rule: Before writing DataWeave, ask: “Am I reading payload, attributes, or a variable?”
