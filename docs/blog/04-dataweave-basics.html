DataWeave for Beginners: Input → Transformation → Output

DataWeave is MuleSoft's language for transforming data. Learn it by looking at the input and expected output first.

Start with a concrete example

Input:

{ "firstName": "Narsing", "age": 26 }

Desired output:

{ "name": "Narsing", "adult": true }

Transformation:

%dw 2.0
output application/json
---
{
  name: payload.firstName,
  adult: payload.age >= 18
}

Arrays and map

payload map (item) -> {
  id: item.id,
  name: item.name
}

Filtering

payload filter (item) -> item.active == true

The beginner workflow

  1. Write the exact input.
  2. Write the exact expected output.
  3. Identify fields that move unchanged.
  4. Identify fields that need calculation or lookup.
  5. Write the smallest transformation.
  6. Test edge cases such as null, empty arrays and missing fields.
Practice tip: Do not memorize functions first. Practice describing the transformation you need, then choose the DataWeave function that expresses it.
