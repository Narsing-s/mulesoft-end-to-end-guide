ABOUT THIS BLOG

Built for learning, not memorization.

MuleJourney is an independent open-source educational project. The goal is to make MuleSoft easier to learn by explaining each concept with a clear reason, a small example, expected output, common mistakes and a next step. The blog complements the repository; the repository remains the complete source of lessons, labs and reference material.

MuleJourney is an independent educational project and is not an official MuleSoft website.
