# 34 — Interview Mastery

This is the canonical interview-preparation area. Questions are arranged by difficulty and topic.

## 01-Easy
- MuleSoft and Anypoint Platform fundamentals
- Mule event/message model
- Flow, subflow, private flow
- Payload, attributes, variables
- HTTP basics
- Basic DataWeave
- Basic connectors

## 02-Intermediate
- RAML/OAS and APIkit
- API-led connectivity
- DataWeave collections and functions
- Error handling
- Database and messaging
- MUnit
- Maven and Git
- CloudHub deployment

## 03-Advanced
- Architecture and integration patterns
- Retry/idempotency/DLQ
- Performance and streaming
- Security and API policies
- CI/CD and deployment strategy
- Observability and production support
- CloudHub 2.0 / Runtime Fabric

## 04-Scenario-Based
Every scenario should contain: symptoms → evidence → investigation → root cause → fix → prevention → interview answer.

## 05-DataWeave
Use input → expected output → solution → line-by-line explanation → edge cases → alternative solution.

## 06-Project Questions
- Project architecture
- API flows
- deployment process
- incident handling
- monitoring
- security
- release/change management

## 07-Managerial / Behavioral
- ownership
- production incidents
- prioritization
- stakeholder communication
- change/release coordination

The goal is reasoning and production understanding, not memorizing answers.
