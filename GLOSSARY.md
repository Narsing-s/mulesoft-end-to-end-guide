# MuleSoft Glossary — Plain English

| Term | Beginner meaning |
|---|---|
| API | A defined way for software to communicate |
| Endpoint | A specific API address/operation |
| HTTP | A common protocol used for web communication |
| REST | A style of designing network APIs around resources and HTTP semantics |
| RAML | An API specification language |
| OpenAPI/OAS | A standard format for describing APIs |
| Mule runtime | The engine that executes Mule applications |
| Mule application | A deployable integration application |
| Flow | Processing steps executed as a unit |
| Mule event | Data/context moving through Mule processing |
| Payload | Main data being processed |
| Attributes | Metadata associated with the message |
| Variable | Temporary event data |
| DataWeave | MuleSoft language for transforming data |
| Connector | Component used to communicate with another system |
| APIkit | Tools for implementing APIs from API specifications |
| SAPI | System API layer |
| PAPI | Process API layer |
| EAPI | Experience API layer |
| Subflow | Reusable processing called by another flow |
| Choice | Conditional routing |
| Scatter-Gather | Run multiple routes and combine results |
| Batch | Framework for large dataset processing |
| MUnit | MuleSoft testing framework |
| Maven | Build/dependency management tool commonly used with Mule projects |
| CI/CD | Automated build/test/release practices |
| TLS | Security protocol used by HTTPS |
| OAuth 2.0 | Authorization framework using access tokens |
| JWT | Token format carrying signed claims |
| CORS | Browser mechanism controlling cross-origin requests |
| Correlation ID | Identifier used to connect related logs/requests |
| Idempotency | Safe handling of repeated logical requests |
| Retry | Attempting an operation again after failure |
| Timeout | Maximum time allowed before an operation stops waiting |
| Throughput | Amount of work handled over time |
| Latency | Time taken for an operation |
| SLA | Defined service-level expectation |
| Runtime Fabric | Infrastructure approach for running Mule applications in Kubernetes-based environments |

## Rule for beginners
If a term is confusing, return to this glossary and explain it in your own words before memorizing the name.
