# Start Here — MuleSoft Zero to Production

If you are completely new, follow this exact order.

## Step 1 — Learn the vocabulary
Read [01-Fundamentals](01-Fundamentals/README.md). Do not move on until you can explain API, integration, flow, event, payload, attributes, variables and connector.

## Step 2 — Build something
Create a Mule project in Anypoint Studio and build a simple HTTP endpoint.

## Step 3 — Learn DataWeave
Read [03-DataWeave](03-DataWeave/README.md). Practice every example by changing the input and predicting the output before running it.

## Step 4 — Build an API
Design a small RAML/OAS contract, scaffold with APIkit, implement it and test it.

## Step 5 — Connect systems
Add a database and an external HTTP service. Learn how errors travel between them.

## Step 6 — Think like an enterprise developer
Study API-led connectivity, routing, messaging, security and testing.

## Step 7 — Think like production support
Study logs, correlation IDs, monitoring and the production scenarios.

## Step 8 — Build the capstone
Complete the banking integration project from [17-Real-World-Project](17-Real-World-Project/README.md).

## How to study each topic
Use this loop:

```text
Read simple explanation
        ↓
See tiny example
        ↓
Build it in Studio
        ↓
Test it
        ↓
Break it intentionally
        ↓
Read the error
        ↓
Fix it
        ↓
Apply it to the banking project
```

This is deliberately practice-first. A beginner should be able to understand a chapter without already knowing MuleSoft terminology.
