## Version-sensitive note

CloudHub 2.0 and modern platform features change over time. The guide intentionally requires learners to record the exact runtime, Java, connector, deployment target, region and tested date for version-sensitive material.

## Package

The authoritative package is generated by `.github/workflows/release-package.yml` when tag `v1.0.0` is pushed. The workflow publishes:

- `mulesoft-end-to-end-guide-v1.0.0.zip`
- `mulesoft-end-to-end-guide-v1.0.0.zip.sha256`

## Integrity

Use the published SHA-256 checksum to verify the downloaded ZIP before extracting it.
