# MuleSoft Interview Scenarios

These are original practice scenarios, not leaked or copied exam questions.

## Beginner
1. What is Mule runtime?
2. What is a Mule event?
3. Payload vs attributes vs variables?
4. Flow vs subflow vs private flow?
5. What is DataWeave?
6. What is RAML?
7. What does APIkit do?

## Intermediate
8. How do you handle a DB timeout?
9. Difference between propagate and continue?
10. When would you use Scatter-Gather?
11. How do you protect an API?
12. How do you pass environment properties?
13. How do you test a connector call with MUnit?
14. How do you prevent duplicate processing?

## Advanced
15. Design a payment API with retry and idempotency.
16. Design an API that combines customer, account and card data.
17. Explain how you would troubleshoot a sudden latency increase.
18. How would you design asynchronous payment processing?
19. How would you deploy the same application to development, test and production?
20. How would you migrate a Mule 3 application to Mule 4?
21. How would you design for downstream outage?
22. How would you prevent sensitive information from entering logs?

## Scenario answer framework
Use:
1. Requirement.
2. Assumptions.
3. Architecture.
4. Mule components.
5. Data transformation.
6. Error handling.
7. Security.
8. Testing.
9. Deployment.
10. Monitoring.
11. Failure recovery.
