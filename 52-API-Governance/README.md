# 52 — API Governance

Govern APIs as products, not only as implementation artifacts.

## API lifecycle
- Discover
- Design
- Review
- Publish
- Implement
- Secure
- Deploy
- Monitor
- Version
- Deprecate
- Retire

## Governance
- RAML/OAS standards
- Naming conventions
- Resource and method design
- HTTP semantics
- Error contract standards
- Pagination/filtering/sorting
- Versioning and compatibility
- Security requirements
- Documentation requirements
- Reuse through Exchange

## Platform governance
- API Manager
- API policies
- API instances
- API portals/catalogs
- API analytics
- Access and ownership
- Environment separation
- Approval workflows

## Reviews
Create reusable review checklists for:
- API design
- Security
- Performance
- Operability
- Data privacy
- Backward compatibility
- Production readiness

## Practical exercises
- Review a poorly designed API
- Convert requirements into RAML/OAS
- Define a versioning strategy
- Apply policies to an API
- Create a governance checklist
- Perform a production-readiness review
