## Distribution contract

The learner package is documentation-first and static. A learner does not need a backend service or database just to read the guide and use the portal. Optional hands-on projects may have their own runtime prerequisites.

## Expected learner outcome

By completing the package, a learner should be able to explain MuleSoft concepts clearly, implement integrations, transform data with DataWeave, write tests, reason about failure, troubleshoot production incidents, discuss deployment/security/observability, document architecture decisions and present an end-to-end project honestly in an interview.
